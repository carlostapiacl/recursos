# Recursos

Lo que voy publicando para trabajar con agentes de código, ordenado por nivel. Cada recurso se puede usar hoy: pasos,
plantillas y comandos probados, con la versión con que se probaron.

Los explico en [carlostapia.cl](https://carlostapia.cl) y en Instagram, en la serie *Agentes sin humo*.

## Básico

- [Agentes sin humo · 1](basico/agentes-sin-humo/): varios agentes de Claude Code a la vez en la terminal. Una pestaña
  con nombre por agente, uno que coordina y un repo git que guarda todo. Incluye la plantilla del repo del equipo.

## Intermedio

- [¿Cuánto tiempo sobrevive el código de tus agentes?](intermedio/supervivencia-de-codigo/): un script que mide qué
  parte de lo escrito cada semana sigue viva con el paso de las semanas, con `git blame`. Incluye mi medición.
